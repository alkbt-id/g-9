# G · NINE

Го 9 × 9 с ботом твоего ранга. Страница целиком работает в браузере: бот — сеть KataGo, обученная играть как
человек заданного ранга (b18c384nbt-humanv0 из [KataGo v1.15.0](https://github.com/lightvector/KataGo/releases/tag/v1.15.0)),
переведённая в ONNX и запущенная через [onnxruntime-web](https://www.npmjs.com/package/onnxruntime-web) 1.31.1 (MIT).
Ранг и партии хранятся только в этом браузере.

Собрано `npm run build:pages` из проекта nine; здесь только готовая страница.
